# 경기도 응급의료기관 수용능력 공식자료

수집 기준일: 2026-09-10 KST

## 확보한 자료

1. 건강보험심사평가원 `전국 병의원 및 약국 현황 2026.6`
   - 공식 페이지: https://opendata.hira.or.kr/op/opc/selectOpenData.do?sno=11925
   - `hira_nationwide_hospitals_pharmacies_2026_06.zip`은 원본 ZIP이다.
   - 시설정보, 의료장비정보, 특수진료정보를 사용했다.
   - 병상수는 2026년 6월 정적 시설 신고 스냅샷이며 현재 가용 병상수가 아니다.
2. 중앙응급의료센터 `2024년도 응급의료기관 평가`
   - 공식 페이지: https://www.e-gen.or.kr/nemc/business_medical_institution_evaluation.do?tabId=9
   - 경기도 공개 조회 결과 73행과 전체 기관 PDF를 보존했다.
   - 평가종합등급, 인력, 병상포화, 중증환자 재실시간, 최종치료 제공률 등은 연간 평가등급이다.
   - 실제 환자 도착시점의 수용 여부를 뜻하지 않는다.

## 73개 병원 결합 결과

- `hospital_capacity_hira_matched_73.csv`: 프로젝트의 73개 병원과 HIRA 시설정보 결합 결과
- `hospital_evaluation_egen_matched_73.csv`: 73개 병원과 2024년 E-Gen 평가 결과 결합 결과
- HIRA 결합은 73행 중 72개 고유 요양기관이다.
- 용인시의 `명주병원`과 `메디필드한강병원`은 프로젝트 입력에서 주소가 동일하고, 2026년 6월 HIRA 자료에서는 `메디필드한강병원` 하나로 확인된다. 둘을 서로 다른 병원으로 중복 집계하면 안 되며 명칭 이력 확인이 필요하다.
- HIRA 자동결합 검토대상은 위 1행이다. 나머지 72행은 정규화 명칭 또는 주소·명칭 결합점수 기준을 통과했다.
- 2024년 E-Gen 평가와 현행 프로젝트 명단 사이에는 명칭 변경·신규 지정 가능성이 있어 4행을 검토대상으로 표시했다. 연간 평가에 없는 현행 기관에 다른 기관의 등급을 대신 적용하면 안 된다.

수원시 7개 기관은 모두 HIRA 정적 병상자료와 결합되었고 검토대상은 0행이다. 합계는 응급실 병상 201개, 중환자 병상 359개다. 이 값은 2026년 6월 시설 스냅샷 합계이며 실시간 가용량이 아니다.

## 실시간 자료와 정적 자료의 구분

실시간 응급실 가용 병상과 질환별 수용 가능 여부는 공공데이터포털의 국립중앙의료원 `전국 응급의료기관 정보 조회 서비스`에서 제공한다.

- 공식 활용신청 페이지: https://www.data.go.kr/data/15000563/openapi.do
- 공식 인증 파라미터명: `serviceKey`
- 실시간 가용 병상 오퍼레이션: `getEmrrmRltmUsefulSckbdInfoInqire`
- 중증질환 수용 가능 오퍼레이션: `getSrsillDissAceptncPosblInfoInqire`

이 API는 별도의 활용신청 승인이 필요하므로 이번 수집에는 포함하지 않았다. 한 시점의 실시간 값을 병원의 고정 수용능력으로 저장하지 말고, 시뮬레이션에는 반복 수집한 시간대별 가용률 분포 또는 상태 전이모형으로 넣어야 한다.

## 컬럼 해석 주의

- `응급실병상수`: 정적 시설 병상수
- `critical_care_beds_total`: 성인·소아·신생아 중환자 병상수 합계
- `inpatient_beds_total_from_reported_fields`: HIRA가 제공한 입원·중환자·정신·격리·무균 병상 필드의 합계
- `수술실병상수`, `ct_units`, `mri_units`, `pet_units`: 정적 시설·장비 수
- `registered_*`: HIRA 특수진료정보에 등록된 정적 여부
- E-Gen `*_grade`: 2024년도 평가등급이며 확률이나 실시간 수용률이 아님

파일별 SHA-256, 크기, 행수와 출처는 `source_manifest.json`에 기록했다.
